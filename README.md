# Prévia do site · Instituto Angélica Federizzi

Prévia de apresentação feita pela RK Performance (outubro de 2026). Não é o site oficial da clínica: textos e dados estão marcados "a confirmar" e a página não é indexada (`noindex` + `robots.txt`).

- `index.html`: home.
- `reestruturacao-facial-guarapuava/`: exemplo de página de procedimento.
- `assets/`: CSS e JS.
- `media/`: fotos e vídeos do Instagram público da clínica, recortados para a prévia. Nenhuma imagem de paciente.

Os botões de WhatsApp e telefone abrem um aviso de demonstração. No site final, abrem o WhatsApp do Instituto com a mensagem de cada página.
